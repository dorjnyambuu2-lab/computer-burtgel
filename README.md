# Компьютер бүртгэл

Байгууллагын компьютерийн тоног төхөөрөмжийн бүртгэлийн систем (Laravel 12 + Tailwind CSS 4).

## Боломжууд
- Нэвтрэх / гарах (session, throttle)
- Хяналтын самбар: төлөв, төрөл, алба хэлтсээр статистик, баталгаат хугацаа дуусах гэж буй компьютерууд
- Компьютер нэмэх / харах / засах / устгах (серийн, IP, MAC, RAM, CPU, хариуцагч, баталгаа гэх мэт)
- Хайлт + төлөв / төрөл / алба хэлтсээр шүүх, хуудаслалт
- CSV татах (Excel дээр кирилл зөв харагдана)

## Суулгах

> **Чухал:** zip-ийг **шинэ хоосон хавтсанд** задлаарай (жишээ нь `C:\xampp\htdocs\web\computer-registry`).
> Өмнөх төслийн хавтасны дээр задалбал хуучин `routes/web.php`, `views` зэрэг нь давхцаж алдаа гарна.
> `.env` доторх `DB_DATABASE`-д **шинэ, хоосон** өгөгдлийн сан өгнө (хуучин өгөгдлийн сан дахь `users` хүснэгттэй зөрчилдөхгүйн тулд).

1. MySQL дээр `computer_registry` нэртэй өгөгдлийн сан үүсгэнэ (`.env` дэх `DB_*` утгыг шалгана).
2. Дараах тушаалуудыг ажиллуулна:

```bash
composer install
npm install
php artisan migrate --seed
npm run build        # хөгжүүлэлтийн үед: npm run dev
php artisan serve
```

3. http://127.0.0.1:8000 нээгээд Супер админаар нэвтэрнэ:
   - Нэвтрэх нэр: `superadmin`
   - Анхны нууц үг: `superadmin123` (`.env` дэх `SUPERADMIN_DEFAULT_PASSWORD`). Нэвтэрмэгц шинэ нууц үг солиулна.

## Эрх
| Эрх | Боломж |
|---|---|
| Ажилтан | Өөрийн төхөөрөмж, засварын төлөв (#дугаар, явц) харах, эвдрэл / захиалгын хүсэлт илгээх |
| Админ | Компьютер бүртгэх, засварт оруулах, засварын явц өөрчлөх, дараалал зохицуулах |
| Супер админ | Дээрх бүгд + админ, ажилтан бүртгэх, бүрмөсөн устгах, нууц үгийн хүсэлт шийдвэрлэх |

## Засварын дараалал ба мэдэгдэл
- Компьютер «Засварт» болмогц дарааллын төгсгөлд орж `#1, #2, #3 …` дугаартай харагдана (`/repairs`).
- Явц: Дараалалд → Оношилгоо → Засаж байна → Сэлбэг хүлээж буй → Засвар дууссан. Дээш / доош шилжүүлж болно.
- Явц өөрчлөгдөх бүрд хариуцагч, эвдрэл мэдээлсэн ажилтан, админуудад **систем дотор (🔔) болон имэйлээр** мэдэгдэл очно.
- Өдөр бүр `REPAIR_DIGEST_TIME` (09:00) цагт засварын жагсаалт админуудад очно. Үүнд scheduler ажиллах ёстой:
  Windows Task Scheduler-т минут тутам `php C:
mpp\htdocs\web\laravel\artisan schedule:run` нэмнэ (гараар: `php artisan repairs:digest`).
- Имэйл жинхэнээр илгээхийн тулд `.env` дэх `MAIL_*`-г SMTP-ээр тохируулна (`MAIL_MAILER=log` үед `storage/logs`-д бичигдэнэ).

## Устгах
- «Устгах» нь логик устгалт: бааз дээр архивлагдаж, «Устгасан» хэсгээс сэргээж болно.
- «Бүрмөсөн устгах» нь зөвхөн Супер админд, нууц үгээ дахин оруулж баталгаажуулна.

## Нууц үг сэргээх
- **Супер админ:** «Нууц үгээ мартсан?» → имэйлээр нэг удаагийн холбоос → `SUPERADMIN_RECOVERY_KEY` түлхүүр + шинэ нууц үг.
  Имэйл / түлхүүр байхгүй бол серверээс: `php artisan superadmin:reset-password`.
- **Админ / ажилтан:** «Нууц үгээ мартсан?» → хүсэлт Супер админ руу автоматаар очно → Супер админ «Нууц үгийн хүсэлт» хэсгээс түр нууц үг олгоно → нэвтэрмэгц солино.

`php artisan migrate --seed` нь 25 жишээ компьютер үүсгэнэ. Жишээ өгөгдөл хэрэггүй бол
`database/seeders/DatabaseSeeder.php` доторх `Computer::factory()` мөрийг устгана.

## Түгээмэл алдаа
| Алдаа | Шийдэл |
|---|---|
| `Table 'users' already exists` | Хоосон өгөгдлийн сан ашиглах, эсвэл (өгөгдөл хэрэггүй бол) `php artisan migrate:fresh --seed` |
| `'vite' is not recognized` | `npm install` дуустал хүлээгээд `npm run build` (Node.js суулгасан байх ёстой) |
| `Vite manifest not found` | `npm run build` эсвэл `npm run dev` ажиллуулна |
| `Call to undefined method ...::index()` | Хуучин `routes/web.php` үлдсэн. Zip доторх `routes/web.php`-ээр солино |
| Өөрчлөлт харагдахгүй | `php artisan optimize:clear` |
